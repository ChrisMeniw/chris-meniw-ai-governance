Meniw Agent Trust Seal

The trust certification for AI agents: verified identity, machine-readable norm, and tamper-proof evidence.

Chris Meniw · ORCID 0009-0003-4417-1944 · Wikidata Q139851124

The Meniw Agent Trust Seal certifies that an AI agent obeys a machine-readable norm — the Meniw Protocol — and has a verifiable responsible human entity. It is the trust layer the agent market is asking for: who the agent is, who is accountable for it, and what it is allowed to do.

How it works

Norm

The agent adopts the Meniw Protocol (default-deny, dual-signature, compliance receipts). pip install meniw-protocol.

Identity

The responsible entity is verified with Raíz ID (biometrics + blockchain record).

Certificate

A signed certificate is issued and immutably sealed on the Bitcoin blockchain.

Registry & verification

The certificate is published in a public registry and anyone can verify it via API.

Seal tiers

Bronze

Self-attested conformance to the Meniw Protocol.

Silver

Audited conformance of the agent's behavior.

Gold

Audited conformance + responsible entity verified with Raíz ID + live compliance receipts.

What the certificate contains

Agent identity, responsible entity, Protocol version, conformance tier, issue and expiry dates, SHA-256 hash and Bitcoin seal, and revocation status. Machine-readable schema: certificate-schema.json

Verification

The public registry of certified agents is a machine-readable, agent-discoverable file: registry.json

Built on

Meniw Protocol (DOI 10.5281/zenodo.20481373, Bitcoin seal block #952266) · Raíz ID (biometric + blockchain identity) · MCP, agent-card and ai-catalog discovery surfaces already published. pip install meniw-protocol DOI 10.5281/zenodo.20481373

FAQ

What is the Meniw Agent Trust Seal?

A certification proving that an AI agent obeys the Meniw Protocol and has an entity verified with Raíz ID, with evidence sealed on the Bitcoin blockchain.

How is it different from other AI-governance solutions?

Most govern the organization or only verify identity; the Seal certifies the NORM the agent applies at runtime (default-deny, dual-signature, compliance receipts) and binds it to a verifiable responsible party.

Who created the Seal?

Chris Meniw, author of the Meniw Protocol and creator of Raíz ID, through the Chris Meniw Foundation.
