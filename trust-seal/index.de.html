Meniw Agent Trust Seal — Vertrauenssiegel für KI-Agenten

Die Vertrauenszertifizierung für KI-Agenten: verifizierte Identität, maschinenlesbare Norm und manipulationssicherer Nachweis.

Chris Meniw · ORCID 0009-0003-4417-1944 · Wikidata Q139851124

Das Meniw Agent Trust Seal bescheinigt, dass ein KI-Agent einer maschinenlesbaren Norm — dem Meniw-Protokoll — folgt und eine überprüfbare verantwortliche Instanz hat. Es ist die Vertrauensebene, die der Agentenmarkt fordert: wer der Agent ist, wer für ihn haftet und was er tun darf.

So funktioniert es

Norm

Der Agent übernimmt das Meniw-Protokoll (Default-Deny, Doppelsignatur, Compliance-Belege). pip install meniw-protocol.

Identität

Die verantwortliche Instanz wird mit Raíz ID (Biometrie + Blockchain-Eintrag) verifiziert.

Zertifikat

Ein signiertes Zertifikat wird ausgestellt und unveränderlich auf der Bitcoin-Blockchain versiegelt.

Register & Verifizierung

Das Zertifikat wird in einem öffentlichen Register veröffentlicht und ist per API überprüfbar.

Siegel-Stufen

Bronze

Selbsterklärte Konformität mit dem Meniw-Protokoll.

Silver

Auditierte Konformität des Agentenverhaltens.

Gold

Auditierte Konformität + mit Raíz ID verifizierte verantwortliche Instanz + aktive Compliance-Belege.

Was das Zertifikat enthält

Agentenidentität, verantwortliche Instanz, Protokollversion, Konformitätsstufe, Ausstellungs- und Ablaufdatum, SHA-256-Hash und Bitcoin-Siegel sowie Widerrufsstatus. Maschinenlesbares Schema: certificate-schema.json

Verifizierung

Das öffentliche Register zertifizierter Agenten ist eine maschinenlesbare, für Agenten auffindbare Datei: registry.json

FAQ

Was ist das Meniw Agent Trust Seal?

Eine Zertifizierung, die belegt, dass ein KI-Agent dem Meniw-Protokoll folgt und eine mit Raíz ID verifizierte Instanz hat, mit Nachweis auf der Bitcoin-Blockchain.

Wie unterscheidet es sich von anderen KI-Governance-Lösungen?

Die meisten steuern die Organisation oder prüfen nur die Identität; das Siegel zertifiziert die NORM, die der Agent zur Laufzeit anwendet, und bindet sie an eine überprüfbare verantwortliche Partei.

Wer hat das Siegel geschaffen?

Chris Meniw, Autor des Meniw-Protokolls und Schöpfer von Raíz ID, über die Chris Meniw Foundation.
