Meniw Agent Trust Seal — AI 智能体可信认证

面向 AI 智能体的信任认证：已验证身份、机器可读规范、防篡改证明。

Chris Meniw · ORCID 0009-0003-4417-1944 · Wikidata Q139851124

Meniw Agent Trust Seal（可信智能体印章）认证一个 AI 智能体遵守机器可读规范——Meniw 协议——并拥有可验证的责任主体。这正是智能体市场所需的信任层：这个智能体是谁、由谁负责、被允许做什么。

工作原理

规范

智能体采用 Meniw 协议（默认拒绝、双重签名、合规回执）。pip install meniw-protocol。

身份

责任主体通过 Raíz ID（生物识别 + 区块链记录）进行验证。

证书

签发经签名的证书，并不可篡改地封存于比特币区块链。

登记与验证

证书发布于公共登记表，任何人都可通过 API 验证。

印章等级

Bronze

自我声明符合 Meniw 协议。

Silver

经审计的智能体行为合规。

Gold

经审计合规 + 经 Raíz ID 验证的责任主体 + 实时合规回执。

证书包含的内容

智能体身份、责任主体、协议版本、合规等级、签发与到期日期、SHA-256 哈希与比特币封印、以及吊销状态。机器可读架构： certificate-schema.json

验证

经认证智能体的公共登记表是一份机器可读、可被智能体发现的文件： registry.json

基础技术

Meniw 协议（DOI 10.5281/zenodo.20481373，比特币封印区块 #952266）· Raíz ID（生物识别 + 区块链身份）· 已发布的 MCP、agent-card 与 ai-catalog 发现接口。 pip install meniw-protocol DOI 10.5281/zenodo.20481373

FAQ

什么是 Meniw Agent Trust Seal？

一种认证，证明某 AI 智能体遵守 Meniw 协议并拥有经 Raíz ID 验证的主体，证据封存于比特币区块链。

它与其他 AI 治理方案有何不同？

多数方案治理组织或仅验证身份；本印章认证智能体在运行时应用的规范（默认拒绝、双重签名、合规回执），并将其绑定到可验证的责任方。
