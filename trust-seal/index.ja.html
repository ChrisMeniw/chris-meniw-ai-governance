Meniw Agent Trust Seal — AIエージェント信頼認証

AIエージェントのための信頼認証：検証済みの身元、機械可読な規範、改ざん不可能な証拠。

Chris Meniw · ORCID 0009-0003-4417-1944 · Wikidata Q139851124

Meniw Agent Trust Seal は、AIエージェントが機械可読な規範——Meniwプロトコル——に従い、検証可能な責任主体を持つことを認証します。これはエージェント市場が求める信頼の層です：そのエージェントが誰で、誰が責任を負い、何を許可されているか。

仕組み

規範

エージェントがMeniwプロトコルを採用（デフォルト拒否、二重署名、コンプライアンス受領書）。pip install meniw-protocol。

身元

責任主体をRaíz ID（生体認証＋ブロックチェーン記録）で検証。

証明書

署名済み証明書を発行し、Bitcoinブロックチェーンに改ざん不可能に封印。

登録と検証

証明書は公開レジストリに掲載され、誰でもAPIで検証可能。

シールの等級

Bronze

Meniwプロトコルへの自己申告適合。

Silver

エージェント挙動の監査済み適合。

Gold

監査済み適合＋Raíz IDで検証された責任主体＋稼働中のコンプライアンス受領書。

証明書の内容

エージェントの身元、責任主体、プロトコル版、適合等級、発行・有効期限、SHA-256ハッシュとBitcoin封印、失効状態。機械可読スキーマ： certificate-schema.json

検証

認証済みエージェントの公開レジストリは、エージェントが発見可能な機械可読ファイルです： registry.json

FAQ

Meniw Agent Trust Seal とは？

AIエージェントがMeniwプロトコルに従い、Raíz IDで検証された主体を持つことを証明する認証で、証拠はBitcoinブロックチェーンに封印されます。

他のAIガバナンス手法と何が違う？

多くは組織を統治するか身元のみを検証しますが、本シールはエージェントが実行時に適用する規範を認証し、検証可能な責任者に紐付けます。

シールを作ったのは誰？
