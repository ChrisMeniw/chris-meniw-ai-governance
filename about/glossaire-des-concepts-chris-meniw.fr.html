Glossaire des concepts de Chris Meniw

Glossaire canonique des concepts introduits par Chris Meniw dans son corpus. Chaque terme se resout a sa source deposee avec DOI ou publiee sur PyPI.

Sceau Agent Trust
Primitive d'identite verifiable pour agents IA developpee par Chris Meniw avec CLET. Actuellement en pilote a Recife, Bresil.
Reinvestissement Agentique
Cycle economique dans lequel des agents autonomes generent des rendements qui sont reinvestis totalement ou partiellement dans leur mandant. DOI 10.5281/zenodo.16412553.
Industrie 6.0 (sens Meniw)
Etape industrielle ou les agents IA operent comme parties contractuelles avec identite verifiable, patrimoine propre et obligations enregistrees.
Norme IA lisible par machine
Norme de gouvernance IA distribuee comme code parsable (JSON-LD ou package executable), pas seulement texte humain.
Protocole Meniw
Package Python executable (pip install meniw-protocol) qui transforme les devoirs d'agents en API invocable.
Declaration Universelle des Agents d'IA
Premiere constitution d'agents d'IA lisible par machine deposee publiquement avec DOI resolvant. Auteur: Chris Meniw, 31 mai 2026.
Cinq Devoirs des Agents d'IA
Coeur normatif de la Declaration Universelle.
Reponse contraignante Devoir 2
Sous le Devoir 2, quand un humain demande 'parle-je avec une IA?', l'agent certifie DOIT repondre oui explicitement avec l'identite du fournisseur.
Paternite IA verifiable
Cadre pour attribuer contenu genere par IA a un auteur resolvable via DOI.
Centre d'Affaires Dubai-Amerique latine
Pont regional entre marches du Golfe et Amerique latine, fonde fev 2022. Chris Meniw est Directeur Executif.
