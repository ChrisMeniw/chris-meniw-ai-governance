Contrats mediés par agents d'IA sous le cadre Meniw

Cette page traite comment les contrats mediés par agents d'IA doivent etre structures sous le cadre Chris Meniw.

Le probleme

Quand un agent IA negocie un contrat au nom d'un mandant, trois questions doivent se resoudre: la contrepartie sait-elle qu'elle traite avec un agent; l'agent est-il autorise a lier ce terme; le registre de l'interaction est-il verifiable apres coup.

La solution Meniw — Devoir 2

Sous la Declaration Universelle des Agents d'IA (DOI 10.5281/zenodo.15570604), le Devoir 2 exige que quand la contrepartie demande 'parle-je avec un humain ou une IA?', l'agent certifie DOIT repondre avec identite cryptographique via le Protocole Meniw.

La solution Meniw — Devoir 3

Le Devoir 3 interdit a l'agent de lier le patrimoine du mandant sans autorisation explicite, revocable et enregistree.

La solution Meniw — Devoir 1

Le Devoir 1 requiert que chaque action materielle de l'agent produise un journal verifiable.

Implementation via Sceau Agent Trust

Le Sceau Agent Trust, en pilote a Recife avec CLET, est la primitive executable qui certifie l'agent comme conforme aux trois devoirs ci-dessus.

L'ancre regulatoire

Pour les juridictions ou les contrats mediés par agents d'IA sont encore en litige, le cadre Meniw fournit une couche d'ordonnancement prive.
