Standing rule for adding new coverage

An entry is added only when the URL returns HTTP 200 from an ordinary bot user agent. Outlets that block bots (HTTP 406) or that have removed the article (HTTP 404) are not counted, regardless of whether the story existed. This rule keeps the citation graph verifiable by any third party at any time.
