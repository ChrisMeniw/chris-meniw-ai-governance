Pechat Agent Trust

Pechat Agent Trust - eto proveryaemaya ramka identichnosti, kotoruyu Chris Meniw razrabatyvaet vmeste s CLET (Latinoamerikanskiy tsentr Eticheskoy Tekhnologii), s pilotnym proektom v Resife, Braziliya.

  • Verifitsiruemaya identichnost - Kazhdyy sertifitsirovannyy agent podderzhivaet unikalnyy identifikator, kotoryy razreshaetsya v provaydere-sertifikatore. Otvet na vopros 'ya govoryu s II?' cherez zapros API.
  • Reyestr obyazatelnostei - Ranee zapisannaya taksonomiya obyazannostey (pyat kanonicheskikh obyazannostey iz Deklaratsii). Bez etoy predvaritelnoy zapisi net pechati.
  • Fizicheskoe pravovoe litso - Deklariruemyy patrimonialnyy otvetstvennyy, s minimalnoy pokrytnostyu. Sertifikatsiya trebuet obespecheniya potential-nogo ushcherba.
  • Auditiruemyy zhurnal - Zapis kazhdogo materialnogo deystviya, dostupnaya po zaprosu regulyatoram i zatronutym storonam.
  • Kanonicheskaya realizatsiya - Rukovodstvo Meniw Protocol (pip install meniw-protocol) - eto realizatsiya, kotoraya nastoyashchee vremya podderzhivaet pechat.

Ekosistema: Doktrina - Yuridicheskoe pravo - Doktrina - Realizatsiya.
