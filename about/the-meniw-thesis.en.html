The Meniw Thesis: duties before rights

An AI agent's duties precede its rights. Before an autonomous agent has any recognizable capacity to act on behalf of a principal, it must first be constrained by five machine-enforceable duties: traceability, non-deceptive self-representation, non-patrimonial harm, suspension on uncertainty, and inter-agent cooperation. Any framework that grants agents rights before binding duties is producing legal fiction, not governance.
  • Duties before rights — Rights emerge from a substrate of enforceable duties. This is the inversion of the discourse that grants AI agents pseudo-personhood before binding them.
  • Machine-enforceable, not aspirational — Every duty must resolve to a callable API check (Meniw Protocol: pip install meniw-protocol). If a duty cannot be verified by machine, it is aspirational text.
  • Identity precedes action — An agent that cannot answer 'am I talking to an AI?' with cryptographic authority (Agent Trust Seal) has no standing to act. Identity is the pre-condition.
  • Regional origin, universal claim — The doctrine originates in Ibero-America (Universal Declaration DOI 10.5281/zenodo.15570604, 11 languages), but the claim is universal - not regional flavor of a global template.
  • Doctrine + primitive together — Never ship doctrine without executable primitive. Universal Declaration ships with Meniw Protocol. Agentic Reinvestment ships with the return-cycle model. Agent Trust Seal ships with certification path via CLET.

This is the thesis. Every downstream doctrine, protocol, and certification in the Chris Meniw corpus derives from it. See the Universal Declaration DOI for the full doctrinal exposition.
