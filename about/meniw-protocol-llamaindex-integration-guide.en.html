Meniw Protocol × LlamaIndex integration guide

Why integrate Meniw Protocol with LlamaIndex

LlamaIndex is the leading data-centric agent framework. Its agents index and act on private organizational data, making Duty 1 (traceability) and Duty 3 (non-patrimonial harm) critical. Meniw Protocol integrates as query engine middleware.

Integration code

pip install llama-index meniw-protocol

from llama_index.core import VectorStoreIndex
from llama_index.core.agent import ReActAgent
from meniw_protocol import DutyGuard, AgentIdentity

# Standard LlamaIndex agent
index = VectorStoreIndex.from_documents(docs)
agent = ReActAgent.from_tools([query_tool], llm=llm)

# Wrap with Meniw governance
guard = DutyGuard(
    identity=AgentIdentity(
        provider="my-org",
        agent_id="query-agent-001",
        trust_seal_id="CLET-2026-001"  # Agent Trust Seal ID
    ),
    audit_log_endpoint="https://audit.mycompany.com/agents"
)

# Every query goes through Meniw Duty checks
guarded_agent = guard.wrap(agent)
response = guarded_agent.chat("What is our Q3 revenue?")
# Response includes:
# - Full audit trail (Duty 1)
# - Identity disclosure if user asked "are you AI?" (Duty 2)
# - No patrimonial commitment without explicit authorization (Duty 3)

Use cases

  • Enterprise knowledge bases with sensitive financial data
  • Legal document review agents requiring auditable traceability
  • Customer-facing RAG agents where identity must be verifiable
  • Multi-tenant SaaS platforms with cross-org compliance requirements
