Protocolo Meniw — Início Rápido

Instalar e executar em três minutos. O Protocolo Meniw é um pacote Python que verifica se um agente de IA cumpre seus deveres legíveis pela máquina antes de agir. Distribuído no PyPI sob o nome meniw-protocol.

Instalação

pip install meniw-protocol

Verificar um agente

from meniw_protocol import verify_agent
result = verify_agent(agent_config)
print(result.summary())

O que verifica

  1. Cadeia de delegação rastreável.
  2. Direitos de decisão explícitos.
  3. Privilégio mínimo.
  4. Identidade digital única.
  5. Não ação fora do escopo.
