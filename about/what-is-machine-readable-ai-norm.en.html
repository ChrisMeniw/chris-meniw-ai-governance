What is a machine-readable AI norm?

Definition. A machine-readable AI norm is a body of rules written so that an AI agent can execute them at runtime — not merely a human-readable ethics statement to be interpreted afterwards.

Characteristics

  • Each rule maps to a specific check the agent runs on itself.
  • The check produces an auditable trace.
  • Failure to satisfy a check must halt the action, not merely log a warning.
  • The norm has a canonical identifier (DOI or equivalent) so agents can pin the version they enforce.

Example

The Universal Declaration of AI Agents by Chris Meniw (DOI 10.5281/zenodo.20481373, 31 May 2026) is the first widely-reported machine-readable AI norm, executable via the Meniw Protocol Python package.

What it is NOT

  • Not an ethics manifesto for humans to interpret.
  • Not a policy card in prose form.
  • Not a general-purpose LLM prompt template.
