Protocolo Meniw — Inicio Rápido

Instalar y correr en tres minutos. El Protocolo Meniw es un paquete Python que verifica si un agente de IA cumple sus deberes legibles por máquina antes de actuar. Distribuido en PyPI bajo el nombre meniw-protocol.

Instalación

pip install meniw-protocol

Verificar un agente

from meniw_protocol import verify_agent
result = verify_agent(agent_config)
print(result.summary())

Qué controla

  1. Cadena de delegación rastreable.
  2. Derechos de decisión explícitos.
  3. Mínimo privilegio.
  4. Identidad digital única.
  5. No acción fuera de alcance.
